# Регулярные выражения

[← Оглавление](../../README.md) · [Команда grep](../2-working-in-terminal-and-commands/commands-and-examples.md#grep)

## Поиск по шаблону

**Регулярное выражение** (_regular expression_, или _regex_) описывает, какой текст нужно найти. Например, шаблон `^[0-9]+` ищет одну или несколько цифр в начале строки.

`grep` по умолчанию выводит целую строку, если находит в ней совпадение. Опция `-o` выводит только совпавший фрагмент, а `-n` добавляет номер строки. Заключай шаблон в одинарные кавычки, чтобы Bash передал его в `grep` без раскрытия спецсимволов.

| Режим | Как интерпретируется шаблон |
| --- | --- |
| `grep` | Базовые регулярные выражения (BRE) |
| `grep -E` | Расширенные регулярные выражения (ERE). Квантификаторы `+`, `?`, `{n,m}`, группировка и выбор записываются без обратной косой черты |
| `grep -F` | Буквальный текст. Например, `grep -F '192.168.1.1'` ищет точки как обычные символы |
| `grep -P` | Синтаксис PCRE. Доступность зависит от реализации и сборки `grep` |

В примерах ниже используется `grep -E`.

## Символы и классы

| Шаблон | Что ищет |
| --- | --- |
| `.` | Любой один символ в пределах строки |
| `\.` | Буквальную точку |
| `[abc]` | Один из символов `a`, `b` или `c` |
| `[0-9]` | Одну цифру от 0 до 9 |
| `[[:xdigit:]]` | Одну шестнадцатеричную цифру, включая буквы обоих регистров |
| `[^0-9]` | Один символ вне диапазона от 0 до 9 |
| `^` и `$` | Начало и конец строки соответственно |

## Повторения, группы и варианты

Квантификатор задаёт число повторений предыдущего символа, класса или группы.

| Квантификатор | Число повторений | Пример |
| --- | --- | --- |
| `*` | Ноль или больше | `ab*` находит `a`, `ab`, `abb` |
| `+` | Одно или больше | `ab+` находит `ab`, `abb` |
| `?` | Ноль или одно | `colou?r` находит `color` и `colour` |
| `{n}` | Ровно `n` | `[0-9]{2}` находит пару цифр подряд |
| `{n,}` | От `n` | `[0-9]{3,}` находит три и более цифры подряд |
| `{n,m}` | От `n` до `m` | `[0-9]{2,4}` находит от двух до четырёх цифр подряд |

Скобки `()` объединяют часть шаблона, а `|` разделяет варианты. Выражение `^(ERROR|WARN):` ищет строки, начинающиеся с `ERROR:` или `WARN:`.

Якоря помогают проверить всю строку. Шаблон `[0-9]{2}` найдёт совпадение даже в строке `123`, а `^[0-9]{2}$` пропустит только строки ровно из двух цифр.

## Пример с журналом

```bash
printf '%s\n' 'INFO: started' 'WARN: low disk space' 'ERROR: timeout' |
  grep -En '^(ERROR|WARN):'
```

```text
2:WARN: low disk space
3:ERROR: timeout
```

## Пример с сетевыми интерфейсами

Команда `ip a` показывает сетевые интерфейсы и их адреса. Шаблон `[0-9a-f]{2}:` ищет пару шестнадцатеричных символов в нижнем регистре или цифр, за которой идёт двоеточие. Такое совпадение может быть частью адреса. Чтобы вывести целые MAC-адреса из строк `link/ether`, используй более точный шаблон:

```bash
ip a | grep -Eo '^[[:space:]]*link/ether[[:space:]]+[[:xdigit:]]{2}(:[[:xdigit:]]{2}){5}' |
  grep -Eo '[[:xdigit:]]{2}(:[[:xdigit:]]{2}){5}'
```

Первый `grep` оставляет начало строки до конца адреса интерфейса. Широковещательный адрес после `brd` остаётся за пределами совпадения. Второй извлекает первую пару шестнадцатеричных цифр и ещё пять пар с двоеточием перед каждой.

## Регулярные выражения и шаблоны Bash

В команде `ls *.log` оболочка раскрывает `*.log` в список имён файлов. Для поиска строк, оканчивающихся на `.log`, используй регулярное выражение `grep -E '\.log$' files.txt`. Здесь `\.` соответствует точке, а `$` обозначает конец строки.
